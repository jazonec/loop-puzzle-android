# Соты · Slitherlink

## Android / GitHub Actions

Android-версия собирается на GitHub, без Android SDK или JDK на ноутбуке. Откройте **Actions → Android debug APK**, дождитесь успешной сборки и скачайте архив **loop-puzzle-debug-apk** в разделе **Artifacts**. Внутри — `loop-puzzle-debug.apk` с debug-подписью для Android 8.0 и новее.

Игра упакована внутрь APK и работает без интернета. Прогресс Android-приложения хранится отдельно от браузерной версии. Подробности сборки и установки — в [android/README.md](android/README.md).

## Браузерная версия

Браузерная игра на русском языке. Поле — правильный шестиугольник со стороной 12 сот: 397 ячеек, 1260 рёбер и 864 вершины.

Поле оформлено как бумажная головоломка: кремовый фон, пунктирные рёбра, тёмные вершины и цветные линии с тонкой обводкой. Связанные линии имеют общий цвет; при объединении фрагментов сохраняется преобладающий цвет. Явные противоречия подсвечивают число красным сразу после хода.

Когда число линий у соты совпадает с её числом, остальные рёбра автоматически исчезают. У нулей они скрыты сразу. Исключения распространяются через вершины: третья ветка при двух выбранных линиях и одиночные тупиковые цепочки убираются. Изолированные точки также скрываются. Автоматические исключения пересчитываются после каждого хода и отмены; выбранные игроком линии не удаляются.

## Запуск

Нужен Node.js 22 или новее. Внешние npm-зависимости отсутствуют.

```sh
npm start
```

Откройте http://127.0.0.1:5173. `npm test` проверяет геометрию, генератор и правила победы. `npm run build` собирает статическую версию в `dist/` для любого HTTP-хостинга.

## Правила и управление

Число в соте равно числу линий на её границе. Все линии образуют единственный замкнутый контур без ветвлений. Крестики — необязательные заметки об исключённых рёбрах.

- ЛКМ: пустое ребро → линия → крестик → пустое ребро.
- ПКМ: пустое ребро → крестик → линия → пустое ребро.
- Колесо, щипок и кнопки изменяют масштаб; перетаскивание фона перемещает поле.
- Ctrl+Z / Ctrl+Y: отмена / повтор. Tab переводит фокус на поле, стрелки выбирают ребро, Enter меняет состояние, X ставит крестик.
- Прогресс и время сохраняются в localStorage. Новая игра и очистка требуют подтверждения при наличии ходов.

Генератор строит связную область без дыр и выводит числа из её границы. Каждая задача имеет решение, проверяемое тестами; единственность решения не гарантируется. Игра принимает любой контур, удовлетворяющий правилам. Подсказки открывают рёбра исходного решения, поэтому могут отличаться от другого допустимого пути игрока.

Приложение работает без внешних сервисов; необязательный шрифт Manrope загружается из Google Fonts с системным запасным шрифтом.
